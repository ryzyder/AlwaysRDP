# Changelog

## 1.0.0 — 2026-11-10

First source repository packaging of AlwaysRDP, including:

- Saved profiles and DPAPI-protected per-profile passwords.
- Windows native RDP credential handoff with normal cleanup.
- Full-screen sessions on virtual Desktop 2 and reconnect supervision.
- Grace handling for intermediate RDP disconnect events during sign-in.
- Optional Windows startup and per-profile local resource sharing.
- Confirmed profile deletion and persistence of an empty profile list.
- English, Spanish and Portuguese interfaces with remembered language selection.
- Build scripts, synthetic regression tests, project attribution and third-party notices.

This is the first packaged source history, not a reconstruction of earlier development commits.
